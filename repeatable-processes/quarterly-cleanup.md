# Quarterly Todo Cleanup

Run every 3 months. Tracked by the perpetual task in `todo/todo.md`.

## Steps

1. Read the `## Completed` section in `todo/todo.md`
2. Review each item with the user — keep anything still useful as reference
3. Move the rest to `archive/todo-completed.md`
4. Update the `[by YYYY-MM-DD]` date on the perpetual cleanup task to 3 months from today
5. Commit changes
